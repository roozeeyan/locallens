# Записка-передача: перенос данных из Google Maps в LocalLens

> Это хэндофф от облачной сессии для сессии, запущенной **на Маке** (с доступом к браузеру).
> Ветка: `claude/locallens-content-population-gkCQI`

## Цель, которую поставила Рузанна (Roo)

Зайти в её **личную Google-карту** (открыта в Chrome на Маке) и **перенести в приложение
LocalLens заново, по каждой стране**: сверить точки, перенести правильные описания,
перенести фотографии, проставить точные координаты. Часть данных уже перенесена ранее —
её нужно **сверить**, а не дублировать.

## Текущее состояние данных (`src/data.js`) — на момент передачи

- Всего точек: **925** в 8 городах.
- Города: Ереван (285), Панган (203), Бали (128), Бангкок (117), Самуи (82),
  Дананг (69), Хой Ан (28), Сингапур (13).
- **Описания** есть только у **85 из 925** (~9%).
- **Фотографии** есть только у **2** точек (почти нет).
- **Координаты**: у всех 284 ереванских точек стоят ПЛЕЙСХОЛДЕРНЫЕ координаты
  (`lat: 40.1872, lng: 44.5152` — центр города, одинаковые). На карте они лягут кучей.
  У остальных городов координаты, похоже, реальные (нужно проверить).
- Что есть у всех: `name`, `category`, `mapsUrl` (в mapsUrl зашит реальный Google place ID
  в куске `!1s0x...` — по нему можно матчить место точно).

Структура записи места:
```js
{ id, cityId, category, name, lat, lng, mapsUrl,
  description?, travelAround?, district?, badge?, rooChoice?, tags?, schedule?, photo? }
```

## Что уже есть в репозитории (переиспользовать!)

- В истории ветки есть коммит **"Add Serper photo-fetch workflow and wire photos into places"**
  — механизм подтягивания фото через Serper API. Проверить `package.json`/скрипты.
- Коммит **"Import 937 places from Google Maps collections into data.js"** — прошлый импорт.
- Города и данные: `src/data.js` (`CITIES`, `INITIAL_PLACES`).

## Рекомендуемый план работы (по странам)

1. **Достать источник истины из карты Roo.** Лучший способ — экспорт My Maps в **KML**
   (⋮ рядом с названием карты → «Экспорт в KML/KMZ»). KML даёт названия, описания,
   координаты всех точек разом. Через браузер можно и открыть меню экспорта, и скачать файл.
2. **Матчинг** KML-точек с существующими в `data.js` по place ID (из mapsUrl) или по
   названию+координатам. Пометить: совпало / новое / отсутствует в карте.
3. **Перенести описания и точные координаты** из KML в `data.js` (особенно починить
   284 ереванских плейсхолдера).
4. **Фото**: если Roo сама грузила фото на булавки — они в KML ссылками. Если нужны фото
   Google — использовать уже заведённый Serper-workflow (или Google Places API — это платно,
   согласовать с Roo).
5. Сверять и коммитить **по одной стране за раз**, показывая Roo расхождения.

## Важное про окружение

- Пуш идёт в ветку `claude/locallens-content-population-gkCQI` (НЕ в main —
  на этом сервере main принадлежит другому проекту).
- Сборка: `npm run build`. Прод: locallens-mocha.vercel.app. Код доступа в приложение: 919526.
- В приложении недавно переделан онбординг (тёмный премиум-экран с портретом-персонажем Roo).

## Что сделать первым делом в сессии на Маке

1. Убедиться, что открыта ветка `claude/locallens-content-population-gkCQI`.
2. Попросить Roo открыть её My Maps в Chrome (или дать ссылку с `mid=`).
3. Через браузер выгрузить/скачать KML — и дальше по плану выше.
